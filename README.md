# מודול התייעצות עם רופאים מומחים

מערכת שבה סניפי הרשת שולחים פניות להתייעצות, סמנכ״ל התפעול מסנן ועונה או מעביר לרופא מומחה, והרופא עונה.

- **קוד:** Next.js (App Router), TypeScript, Tailwind
- **מסד נתונים והתחברות:** Supabase, באותו פרויקט של מודול קשרי מרפאות (sofiagrig/dental-branch-directory), כך שהמשתמשים נכנסים עם אותו שם משתמש וסיסמה
- **שרת:** Vercel
- **פרוטוטייפ מאושר:** https://claude.ai/artifact/PKGPC4zcJSBnKmn1vc9y9H

## הרצה מקומית

```bash
npm install
cp .env.example .env.local   # למלא את פרטי Supabase
npm run dev
```

## החלטות

- זיהוי מטופל: שם + 4 ספרות אחרונות של ת״ז, גיל ומין (ללא מספר תיק)
- המרפאה בוחרת רק תחום. כל פנייה עוברת לסמנכ״ל התפעול, שעונה בעצמו או מעביר לרופא מתוך רשימת הרופאים
- שני ערוצים בכל פנייה: "מרפאה" ו"פנימי". המרפאה רואה רק את השאלה ואת התשובות אליה, בחתימת "צוות ההתייעצות". הרופא כותב רק לסמנכ״ל, והסמנכ״ל שולח למרפאה את השורה התחתונה
- תחומי ההתייעצות: כללי, פריו, אנדו, יישור, שיקום, כירורגיה
- מיילים יוצאים (Resend) כוללים רק מספר פנייה וקישור, ללא פרטים רפואיים. בלי הגדרות המייל ב־Vercel לא נשלח כלום
- קבצים נשמרים באחסון פרטי ונפתחים בקישור זמני
